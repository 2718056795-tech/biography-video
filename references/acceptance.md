# 系列成片验收

记录“通过 / 不通过 / 待检查 / 不适用”及对应证据。样式检查、实际动作检查、媒体解码、模型视觉、真人听审和抖音设备预览分别标记；未做的项目不自动通过。

本包版本为 V2.2.1；profile `biography-paper-cut-series-2.2`、证据schema2.2及母版JSON/hash保持不变，已有2.2项目无需格式迁移，旧显示计划仍须预检。此补丁修正开篇/地点引入前的行程提前泄露，持续地名与统一路线规则保留。标题/页脚/地图面板坐标、字体、字号、封面几何与时序保持原值；V2.1地理来源、像素和实际背景可读性检查继续保留。当前地图像素不要求与旧版一致。

## 1. 母版一致性

- 新人物使用`series_frame.py`、`series_map.py`及`series_cover.py`，保存采用的`series_style.json`与字体版本。旧杜甫案例源码只能作为动作和研究参考，不能自由改布局后仍称同一母版。
- 视频1080×1920、30fps、120秒、3600帧、12槽，cut与母版逐一相同。文字字形、字号、锚点、行距、入退场及封面坐标不随人物改变。
- 四款随包字体与映射正确，缺字/字体缺失不静默回退。没有自动缩字号、挪位、自由重断行；仅事件行允许34→32px。超宽名字不造简称，片名/章节题合法精简，引文保留真实原文与出处。
- 地图(96,150)、880×430且无独立标题、侧栏、图例；常规章节题y595，事件/评价分别y1400/y1450，纸色底从y1360开始。完整细节按JSON而非人工近似坐标复核。
- 场景采用允许的stage profile，演员、支撑物与环境统一等比变换；不能为了新场景随意推移固定文字或地图。

## 2. 每集艺术内容与史实

- 有人物艺术简报，含palette token、1—3个有依据的重复意象及逐幕环境/器物/光源/动作与来源关系。整片编码前执行 `python scripts/preview_series_art.py --project <项目目录>/project.json --output <项目目录>/qa/scene-art.png`，查看12幕美术缩略图。它直接调用项目实际渲染用的画面生成器，画面不含母版文字和地图，便于并排辨认布景。
- 按分镜逐幕核对主要环境轮廓和空间构图，重点检查地点或处境切换处。若分镜安排了换景，画面应能凭城门、屋檐、岸线等主要形体读出变化。同地连续或片尾回扣可共用布景，在分镜说明缘由。美术说明字段齐全、颜色差异和人物位置变化均不足以证明换景。修正误复用后重出缩略图，再检查实际编码片段。
- 全集保留粗块面纸切几何、固定材质和运动语法，人物的年龄/衣饰连续。环境与时代、地理或事件有关，不强配酒杯、月亮或古楼；科学工作环境与装置有来源。
- 章节题、年代、地点、事件与证据相符，12幕实际显示`event_summary`和`assessment`；有诗句也保留两行，不只在JSON里填了却没绘制。
- 事件说清发生什么，评价联系处境、选择、创作或影响；事实性论断有证据，原创与原引文区分。只检索到不称已读，不将诗中地名/朋友去向/纪念馆当足迹，不编精确死地。
- 手机正常播放能读主信息；按母版窗口控制短文案，文字无裁边、幽灵重影或遮住动作。缺阅读时间时精简内容，不自行改字位和时序。

## 3. 实际动画与累计路线

逐幕查看实际编码片段，保留至少两个不同相位的解码帧。静态接触表只能说明布局；全画面像素差不能证明关节在动。

| 对象 | 实际应观察到 |
|---|---|
| 行走 | 支撑脚落地、另一腿屈膝抬步、身体前进，非固定双腿整体滑移。 |
| 手与道具 | 肩肘腕相对变化，纸页/笔/桨接触连续；书写有笔尖与墨迹关系。 |
| 船/装置/环境 | 部件有合理驱动，船相对岸线前进；纸角、草叶、雨或机械运动有因果。 |
| 座面和身体 | 头颈无断缝、人物不悬空，脚/座面/桌面/船面支撑清楚。 |
| 开篇与收束 | 有真实物件变化或动作，不能仅靠单张图淡入。 |

地图跨幕保留旧线，当前段按访问顺序增长，到达后当前城市高亮；同地多幕不画自连，回访复用节点。点线、真实海岸和主要河流统一投影、裁切与等比缩放，真实地点不为构图移动；地名可通过固定标注位置与短引线避让，曲线不冒充古道。艺术场景变化不能伪造行程。内陆可没有海岸；不得借不相关海岸、国界或随机山纹充当地理底图。随包 Natural Earth 是概化的现代地理参照，不是唐代河道、古代疆界或精确古道；人物访问证据与底图来源分别记录。

地图验收须包含以下实际证据：

- 有来源的可用地理要素，记录数据文件、来源、公有领域说明、文件哈希及可见海岸/河流段数。狭窄区域默认数据不足时，提供有来源的详细本地线数据，或合理扩大地理视窗；不能用空底图继续交付。
- 每个画面均传入 `SeriesMap.render()` 生成且带 `series_map_evidence` 的非空 RGBA 地图，保存地图与布局记录。缺地图、透明空图、无证据 PNG、来源/引擎/像素哈希不符均应失败。保存或载入地图用 `save_map_png()` / `load_map_png()` 保留嵌入证据及 `.evidence.json`。
- 开篇全时段只显示有来源的地理底图；逐项确认无起点名、城市点、未来点、行程线、路线光晕、增长尖端、引线或范围注记，旧 `overview=true` 也不能恢复它们。
- 首个地点引入前同样只有底图；默认0.3秒起出现起点名/城市点，路线在0.3+0.45=0.75秒之后才增长，未来点与地名直到抵达才出现。后续章节引入前保留已到访历史，只抑制新段/新地点。检查自定义 `per_scene.<id>.location_intro_sec` 的有限性、下限、实际时长及分镜一致性；首幕0..0、后续访问范围连续。
- 在地点引入/增长门槛前与门槛时、每次抵达前后及跨章的实际画面检查路线顺序、旧线保留、当前点与标签。所有已抵达地名持续显示，未来地名隐藏，回访按节点ID去重；相同标签在同一项目不同帧/幕位置不变，布局指纹相同。
- 历史、增长中和完成路线主线均为2.1原生px、alpha210及同一光晕；不允许新段额外加粗，当前点通过圆环强调。海岸/河流底图仍细。标签位置按全路线一次规划，文字在路线之上并用纸色描边；密集地点短引线回到未移动的真实坐标。检查无字间相撞、可见路线盖字、出地图框或引线误指；查看 `label_layout_audit` 中记录的路线相交候选，不能把几何避让优化称为必然零相交。浅底和深底主题都需检查；地图颜色可以为可读性适配，不改变固定坐标、字形或字号。除主题纸底测量外，`map_background_readability` 必须记录实际艺术区域的对比度检查与背景/地图哈希，通过后才可合成；自动计算不能代替手机大小的视觉检查。
- 检查实际合成 RGB 图和地图 PNG 的像素哈希与记录一致，并确认地图、正文、头部与道具无碰撞。`check_series_style.py` 使用 `--frame <PNG> --map <PNG> --require-pixels` 强制核对当前文件；只提交 JSON 记录时 `actual_frame_pixels_verified:false` 和 `actual_map_pixels_verified:false`，不能称已验证实际画面。

## 4. 媒体、封面与双文件交付

实际MP4为H.264/yuv420p、SAR1:1、固定规格；逐帧PTS连续且间隔符合30fps，完整视频/音频解码通过，不只查看标称元数据。固定完整原曲比较AAC载荷序列与同格式PCM，核对起止时间；容器文件哈希不同不等于音乐改变。短样片按区间另验，无声明确标注。自动音乐峰和固定cut不能冒称真人精准听审。

封面必须为真实1200×1500 PNG，长短边5:4、实际宽高4:5，不能颠倒成横图或默认替换成9:16。姓名、片名、钩子句采用固定坐标/字号/字形，当前记录绑定2.2 profile/hash，人物与环境在预留区域重新绘制，色盘和剪影与本集一致；不是视频截图或硬裁。缩略图检查文字正确可读、轮廓可辨、无裁边。

`verify_cover.py`只检PNG解码、尺寸和哈希，不做OCR或审美认证。`check_delivery.py`必须找到实际视频与实际封面，并绑定通过的媒体报告与当前视频SHA256。交付链接指向正确新版；空配置、假数据演示和线框不能当完成品。附来源、艺术简报、代码、素材、样式/字体记录与验收；未做的真人听审、平台实机检查保持待检查。只有用户明确修改全局规格才另立母版版本。


## 5. 版本证据边界

V2.1 的 [map-upgrade-check.json](map-upgrade-check.json) 和3秒样片保留为 **HISTORICAL V2.1 evidence（历史 V2.1 证据）**；原报告哈希仅对应其固定提交中的文件。V2.2 的 [map-labels-check.json](map-labels-check.json) 与6秒样片也作为 **HISTORICAL V2.2 evidence（历史 V2.2 证据）**，其开篇预览行为已被替换。当前 V2.2.1 实际验证见 [map-opening-check.json](map-opening-check.json) 与 [V2.2.1说明](map-opening-v2.2.1.md)，区分开篇纯底图、引入门槛/路线延迟、无未来城市点、后续历史保留、现有标签/统一笔画、来源/实际像素/背景可读性及真实3秒开篇视频。新样片只证明对应片段，不能称重新完成120秒。未执行的完整渲染、真人听审或设备预览仍记待检查。
