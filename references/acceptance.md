# 系列成片验收

记录“通过 / 不通过 / 待检查 / 不适用”及对应证据。样式检查、实际动作检查、媒体解码、模型视觉、真人听审和抖音设备预览分别标记；未做的项目不自动通过。

## 1. 母版一致性

- 新人物使用`series_frame.py`、`series_map.py`及`series_cover.py`，保存采用的`series_style.json`与字体版本。旧杜甫案例源码只能作为动作和研究参考，不能自由改布局后仍称同一母版。
- 视频1080×1920、30fps、120秒、3600帧、12槽，cut与母版逐一相同。文字字形、字号、锚点、行距、入退场及封面坐标不随人物改变。
- 四款随包字体与映射正确，缺字/字体缺失不静默回退。没有自动缩字号、挪位、自由重断行；仅事件行允许34→32px。超宽名字不造简称，片名/章节题合法精简，引文保留真实原文与出处。
- 地图(96,150)、880×430且无独立标题、侧栏、图例；常规章节题y595，事件/评价分别y1400/y1450，纸色底从y1360开始。完整细节按JSON而非人工近似坐标复核。
- 场景采用允许的stage profile，演员、支撑物与环境统一等比变换；不能为了新场景随意推移固定文字或地图。

## 2. 每集艺术内容与史实

- 有人物艺术简报，含palette token、1—3个有依据的重复意象及逐幕环境/器物/光源/动作与来源关系。新人物既有合适的新配色，也有不同的场景内容，不能只改色仍12幕共用山峦或草堂。
- 全集保留粗块面纸切几何、固定材质和运动语法，人物的年龄/衣饰连续。环境与时代、地理或事件有关，不强配酒杯、月亮或古楼；科学工作环境与装置有来源。
- 章节题、年代、地点、事件与证据相符，12幕实际显示`event_summary`和`assessment`；有诗句也保留两行，不只在JSON里填了却没绘制。
- 事件说清发生什么，评价联系处境、选择、创作或影响；事实性论断有证据，原创与原引文区分。只检索到不称已读，不将诗中地名/朋友去向/纪念馆当足迹，不编精确死地。
- 手机正常播放能读主信息；按母版窗口控制短文案，文字无裁边、幽灵重影或遮住动作。缺阅读时间时精简内容，不自行改字位和时序。

## 3. 实际动画与累计路线

逐幕查看实际编码片段，保留至少两个不同相位的解码帧。静态接触表只能说明布局；全画面像素差不能证明关节在动。

| 对象 | 实际应观察到 |
|---|---|
| 行走 | 支撑脚落地、另一腿屈膝抬步、身体前进，非固定双腿整体滑移。 |
| 手与道具 | 肩肘腕相对变化，纸页/笔/桨接触连续；书写有笔尖与墨迹关系。 |
| 船/装置/环境 | 部件有合理驱动，船相对岸线前进；纸角、草叶、雨或机械运动有因果。 |
| 座面和身体 | 头颈无断缝、人物不悬空，脚/座面/桌面/船面支撑清楚。 |
| 开篇与收束 | 有真实物件变化或动作，不能仅靠单张图淡入。 |

地图跨幕保留旧线，当前段按访问顺序增长，到达后当前城市高亮；同地多幕不画自连，回访复用节点。点线与真实底图统一投影/缩放，地名不为构图随意移动，曲线不冒充古道。检查手机大小下的线与当前城市，以及地图、正文、头部与道具无碰撞。艺术场景变化不能伪造行程。

## 4. 媒体、封面与双文件交付

实际MP4为H.264/yuv420p、SAR1:1、固定规格；逐帧PTS连续且间隔符合30fps，完整视频/音频解码通过，不只查看标称元数据。固定完整原曲比较AAC载荷序列与同格式PCM，核对起止时间；容器文件哈希不同不等于音乐改变。短样片按区间另验，无声明确标注。自动音乐峰和固定cut不能冒称真人精准听审。

封面必须为真实1200×1500 PNG，长短边5:4、实际宽高4:5，不能颠倒成横图或默认替换成9:16。姓名、片名、钩子句采用固定坐标/字号/字形，人物与环境在预留区域重新绘制，色盘和剪影与本集一致；不是视频截图或硬裁。缩略图检查文字正确可读、轮廓可辨、无裁边。

`verify_cover.py`只检PNG解码、尺寸和哈希，不做OCR或审美认证。`check_delivery.py`必须找到实际视频与实际封面，并绑定通过的媒体报告与当前视频SHA256。交付链接指向正确新版；空配置、假数据演示和线框不能当完成品。附来源、艺术简报、代码、素材、样式/字体记录与验收；未做的真人听审、平台实机检查保持待检查。只有用户明确修改全局规格才另立母版版本。
