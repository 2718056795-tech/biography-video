# 系列制作工作流

本版将杜甫V4的字体、字号、信息坐标、12槽时间轴、地图框、封面与动效语法固定为系列母版。每集重新研究人物，设计专属色盘和有事实关系的环境/道具；不能只换名字或颜色而复用全部背景。制作入口是系列合成器，旧杜甫专用脚本只作案例参考。

## 1. 建立来源与艺术简报

读取现有对话、项目和已确认版本；不重复询问尺寸、配乐与风格。新人物逐条登记关键生平、作品原文、年代、古今地点和坐标依据，记录断言ID、来源、支持范围、实际读取状态与争议。仅搜到链接不记作已查；诗中地名、朋友去向和纪念馆不能自动变成传主到访。约年和区域如实标明，不制造精确死地。

绘制前写[人物艺术简报](series-art-direction.md)：本期palette token、1—3个重复意象、年龄轮廓，以及12幕各自的环境、建筑/器物、光源、景别、动作、证据关系和舞台预设。颜色要适合人物，背景内容也要随经历改变。杜甫的草堂、李白的江舟、苏轼的书案田园仅为取材方向；不强制所有集有山、酒杯和月亮。

## 2. 填入固定12槽

依据[系列布局](series-layout.md)与`series_style.json`，固定1080×1920、30fps、120秒、3600帧及12段cut。生平主要节点填入12槽；不是照抄杜甫事件，也不是自行改成10或14幕。只有用户明确修改全局模板时才新建规格版本。

每幕填写独立章节题、年代地点、`event_summary`、`assessment`、可选引文与来源ID、主要动作、环境运动、地图访问范围和stage profile。事件说明回答发生了什么，原创评价联系处境、选择、创作或影响，不能只有诗句、重复事件或空泛赞语。事实部分由来源支持，评价不冒充人物原话。

使用固定字体和阅读窗口精简文字，不让渲染器自动缩字、挪位置、重断行或换字库。唯一尺寸降级是事件行34→32px；仍放不下就合法精简。姓名保持真实、片名/章节题选择准确短题，引用用有出处的短节选，不改造原文塞版。

## 3. 画场景，做真正动作

按照人物艺术简报重画角色与背景，在预设舞台中组织必要的3—5层空间。全系列保持粗块面纸切几何、固定材质与低饱和处理；不因换人物突然转为摄影、厚涂、3D或炫光。场景素材不带另画的标题、地图或页脚。

先做能观察到的动作周期：支撑脚着地换步、笔尖经过留墨、手按住纸角、持桨带动桨杆等。检查头颈、关节、手与道具、身体与座面/地面的接触连续。演员及其支撑物共同采用所选stage profile；不能只移人物导致悬空。环境风雨、纸角、草叶或装置运动有部件和因果。全图移动、字幕淡入、视差和路线增长不能代替人物动画。

## 4. 接入地图、母版文字与原配乐

用`series_frame.py`承担固定排版和文字动效；用`series_map.py`将本人物经纬范围和真实访问顺序绘入固定地图框；用`series_cover.py`完成同系列封面。具体参数以当前模块接口/帮助为准，不另写自由布局替代主合成器。

地图透明、无独立标题与重复侧注；旧线保留，当前段增长并抵达节点，回访复用坐标，同地多幕不生成假迁移。底图、点线统一投影/缩放，轮廓有真实数据来源；连接是叙事示意，不冒充古道。地图图形足够清楚，但框、线型与字号按母版固定。

完整片使用本包原曲起点至结尾并AAC流复制，保留顺序、速度和原音量，不擅改曲、循环、裁切或淡出。系列cut与文字入退场已固定；自动音乐峰只是参考，不冒充听审。用户明确要求先看几秒时，先做3—8秒实际样片再根据反馈替换全片；无声片段明确标注，截取音频对应原曲同一时间。

## 5. 预检、编码与双文件交付

项目预检检查数据、来源引用和艺术简报；系列样式检查核对profile、字体、坐标、字号、cut与渲染设置。检查通过也不证明史料或动画真实，必须继续从实际编码视频中查看动作、章节、事件/评价、地图与阅读时间。

输出实际120秒MP4，做完整媒体检查：尺寸、编码、帧数、逐帧PTS、完整解码、AAC载荷和PCM与固定源一致。另用固定封面合成器实际输出1200×1500 PNG，检查姓名、片名和钩子句位置、字形、缩略图可读性与人物对应。不能用视频截图或9:16裁切代替封面。

运行`verify_media.py`、`verify_cover.py`和`check_delivery.py`，绑定当前文件哈希，分别交付视频与封面。附来源、艺术简报、脚本/分层资源、样式及字体版本与报告。记录“通过/待检查/不通过/不适用”，不将模型抽帧、技术通过混同真人听审或抖音实机预览。常规可逆制作按已有授权持续推进。
