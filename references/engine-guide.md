# 旧杜甫案例工程与研究/动作参考

本页只说明`assets/dufu-reference/`的历史专用工程。新人物一律使用[系列布局](series-layout.md)、随包四款字体和系列主合成器，不按此旧工程自行重写文字布局、改坐标或替换字体。下文的系统字体路径与重跑命令仅适用于复现旧案例。

[杜甫V4参考目录](../assets/dufu-reference/README.md)保留实际使用的Pillow/SVG/FFmpeg工程、史料、图层、文案与配乐。它示范12章生平动画，七处诗句之外每章均有`event_summary`和`assessment`，不能仅换姓名就生成所有人物。新人物必须重新研究、改造故事、图形、动作和行程。

| 模块 | 可复用的方法 | 必须适配的内容 |
|---|---|---|
| `工程/actor_motion.py` | 关节、步态、手与道具联动 | 场景ID、年龄、衣饰、姿态、器物和接触锚点属于杜甫。 |
| `工程/environment_motion.py` | 风雨、竹叶、屋檐与舟桨等局部运动 | 建筑与船体位置、旧静态图层修正、坐姿支撑关系。 |
| `工程/life_map.py` | 透明底图、统一投影、累计路线与回访 | 固定经纬范围、海岸截取、节点和场景顺序；换范围应全部重投影。 |
| `工程/build_art.py` | 生成SVG及PNG分层 | 杜甫的几何形状和时代符号，并非通用素材库。 |
| `工程/render_dufu.py` | 合成舞台、演员、地图、分层文字、视频编码 | 12幕/120秒、文件名、标题、字体路径、布局和每幕舞台变换。 |
| `工程/analyze_audio.py` | 原曲能量与瞬态候选提取 | 候选不等于真人听审；实际切点与动作另行记录。 |
| `工程/verify_output.py` | V4实际PTS、完整解码及源音轨比较 | 默认杜甫输出和120秒竖屏规格；报告仅证明技术范围。 |

通用`project.json`和`data/*.json`脚手架与杜甫`数据/*.json`是两种格式。先完成研究和导演数据，再编写对应渲染器；不能把通用脚手架直接塞进杜甫工程。通用技术检查使用Skill的`scripts/verify_media.py`，它也不证明动画、历史或字幕已通过。

## V4画面与说明评述

完整制作目标为120秒、1080×1920/30fps。实际动画、无标题放大地图、12个人生章节题和七处杜诗延续，并将24句事件/评价加入各幕。完整V4已实际渲染，并通过本版技术验收（0错误）：1080×1920、30fps、3600帧、120秒，实际PTS和完整解码合格，AAC包载荷及解码PCM与固定源音轨完全一致。独立实际编码视频的模型辅助抽帧复核已通过（24句、主要动作、地图与文字避让），最终范围查参考目录中的技术JSON与视觉复核；技术结果不证明主观听审或平台预览通过。包内[6秒S09片段](../assets/biography-commentary-preview.mp4)取自V4全片76秒起，[解码帧](../assets/biography-commentary-preview.png)为实际全片帧2452，不代表用户已给出审美反馈。

事件行y=1400、32—34px加粗Sans；评价行y=1450、30px Sans，颜色`#4D5C4B`。S01分别从0.85/1.45秒入场，其他幕1.15/1.85秒；稳定可读时间按入场结束和退场起点计算。y=1360至画底渐变纸色底保障对比，终章旧页脚移除。主诗仍64px，不能为塞说明将诗缩成小字。

`stage_layout()`将演员、屋檐、纸笔、地面及座面统一等比变换，当前参数为：S01/S09 `(0.60,540)`；S03/S04/S05 `(0.72,420)`；S07 `(0.74,270)`；S08 `(0.78,270)`；其余 `(0.83,275)`，分别为缩放与纵向偏移。新场景需按真实动作与支撑物边界重新评估，不能只移演员或用纸色底盖住动作。

地图880×430置于(96,150)，实际路线/轮廓相对早期版线性放大约1.84倍，没有独立地图标题与重复说明，城市名可保留。放大的是可见地理包围框，点线与底图统一投影；近似定位和路线示意边界保留在工程文档。横版需重新安排地图、标题、诗句和演员，而非最后裁切。

## 依赖、重跑与历史报告

需要Python3.9+、Pillow、NumPy、SciPy、FFmpeg/ffprobe、Inkscape及Noto Sans/Serif CJK。这个旧案例默认`/usr/share/fonts/opentype/noto/`和TTC简体中文索引；只在重现旧案例时按该依赖配置。当前系列母版已另附四款固定字体，新人物不得用系统字库替代或自行修改映射。锁定M4A统一保留在`assets/fixed-bgm.m4a`，来源MOV信息见来源记录；旧案例不重复携带整条MOV和音轨副本。

复制`assets/dufu-reference/`至工作副本后，在副本运行：

```bash
python 工程/render_dufu.py --preview
python 工程/render_dufu.py --render
python 工程/verify_output.py
```

首次无片段缓存需完整渲染。旧报告的绝对路径仅为执行快照，旧哈希和旧时间轴记录用于溯源，不是运行时依赖，也不能作为新项目已通过的凭证。每次新成片重新验收；主观听审和平台设备预览未完成时保持待检查。
