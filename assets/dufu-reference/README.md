# 杜甫参考工程：生平解读动画版 V4

本目录保存杜甫V4实际制作所用的代码、图层、文案、史料、地图与配乐入口。V4为12幕、120秒原生竖屏1080×1920/30fps：保留七处杜诗、12个独立章节题、放大的无标题累计地图及固定原配乐，每幕再显示一句事件说明和一句原创评述，共24句。事件句连接经历与诗作，评价属于本片原创，不冒充杜甫原话。

**V4完整120秒已实际渲染，技术验收通过，0项错误：3600帧、实际PTS与完整解码合格，AAC包载荷及解码PCM与固定源音轨完全一致。** 详见[成片技术验收](质检/成片技术验收.json)；独立实际编码视频的模型辅助抽帧复核已通过（24句、主要动作、地图与文字避让），最终范围见[成片视觉复核](质检/成片视觉复核_v4.md)，不把技术通过等同视觉或真人听审通过。完整MP4不嵌入Skill；包顶层的[6秒实际片段](../biography-commentary-preview.mp4)截取V4全片76秒起的S09，配合[实际解码画面](../biography-commentary-preview.png)（全片帧2452）查看章节、诗句、事件、评价、地图与动作组合。旧地图修订样片不代表本版结果。

## 旧版历史复现说明（新合集不使用此入口）

此段只解释旧版历史行为；若确需完整重放旧程序，先把统一M4A复制回旧程序预期的配乐文件名。新合集直接使用规范化示例和统一入口，不需要重放这些旧命令。需要Python3.9+、Pillow（含`Image.Resampling`）、NumPy、SciPy、FFmpeg/ffprobe、Inkscape及Noto Sans/Serif CJK字体。默认字体路径为`/usr/share/fonts/opentype/noto/`，跨环境先改副本中的字体映射。已有分层图形、GeoJSON、音轨和音乐候选均可离线使用；生成新人物则需新研究和工程适配。

在副本根目录执行：

```bash
python 工程/render_dufu.py --preview
python 工程/render_dufu.py --render
python 工程/verify_output.py
```

完整输出名为`输出/杜甫_此心在人间_生平解读动画版_v4_1080p_120秒.mp4`。本包不保留中间编码片段，首次需完整渲染；`--scenes 2,9`只渲染指定章节，`--assemble`合成全部已有片段，`--resume`仅复用输入指纹及帧数一致的片段。现有`render_preview.py`仍是专用S07局部预览，不能当作包内S09实际片段的导出程序。命令会覆盖副本同名输出。

封面文件作为本例的已完成素材一起保留；新人物需重新构图并检查姓名与片名，不能只改文件名。新输出视频通过技术验收后，按Skill的`verify_cover.py`与`check_delivery.py`核对真实封面和视频，再作为完整交付。

报告中的原环境绝对路径、旧版时间轴来源哈希和`分章结构_v3`等继承文件用于追踪制作过程，不是运行时跨机器路径，也不构成当前V4通过凭证。新渲染必须生成自己的验收。模型辅助视觉检查、机器技术验收、真人全片听审和抖音设备/发布页实机预览分别记录；后两者未完成不得标通过。
