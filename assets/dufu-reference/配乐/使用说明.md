# 固定配乐

本片沿用用户指定的[固定原音轨](../../fixed-bgm.m4a)。来源为用户指定MOV（来源记录留存，整条MOV不作为运行依赖），文件与音轨哈希、流复制提取记录见[锁定信息](配乐锁定信息.json)。该记录始建于模板V1.4，后续原样沿用。

成片从音轨起点连续使用约120秒，保留原始顺序、速度和结尾，合成采用AAC流复制，不重新编码、调速、循环、截曲或新增淡出。画面时间轴微调至原音轨附近的自动瞬态候选，原音频不变。

[音乐分析记录](../数据/音乐检测说明.md)与[完整候选数据](../数据/音乐节拍候选.json)保留了自动分析边界；最终采用的切点以[最终时间轴](../数据/最终时间轴.json)为准。幕内文字有稳定可读入退场，不以候选列表冒充全片主观听审。成片音轨一致性另由验收脚本核对。
