# 杜甫分章结构：12段

120秒分为开篇、10个人生章节和收束，每幕显示独立章节标题。下表是当前代码/数据中的V3分章计划；地图修订已完成120秒整片渲染，技术检查通过，视觉复核另见质检记录。开篇与收束为主题表达，其余对应主要生平节点。

| 时间 | 章节标题 | 年代与地点 | 实际动作安排 |
|---|---|---|---|
| 0.000—6.833秒 | 此心在人间 | 杜甫｜712—770 | 坐写与屋外雨落，建立心系人间的主题 |
| 6.833—15.867秒 | 少年有志 | 青年时期｜吴越、齐鲁漫游 | 青年行走并停步望山 |
| 15.867—26.233秒 | 长安求仕 | 746—755年｜长安 | 携卷走向城门，风旗摆动 |
| 26.233—36.367秒 | 看见饥寒 | 755年｜长安赴奉先途中 | 携包行走，灯笼摆动 |
| 36.367—46.700秒 | 乱中长安 | 757年春｜长安 | 展开家书后抬头，草叶随风弯动 |
| 46.700—56.000秒 | 诗里的百姓 | 757—759年｜凤翔·华州·洛阳 | 挥别与离去，门帘随风摆动 |
| 56.000—66.133秒 | 山路向蜀 | 759年｜秦州—同谷—成都 | 携家行走，入蜀路线依次增长 |
| 66.133—74.833秒 | 草堂春雨 | 761年春（通行说）｜成都 | 落笔蘸墨，竹叶与春雨运动 |
| 74.833—89.200秒 | 天下的屋檐 | 约761年秋｜成都草堂 | 伸手护纸，纸角和屋檐随风翻动 |
| 89.200—100.367秒 | 万里作客 | 767年秋（通行说）｜夔州 | 持杖行走后望江，水纹与落叶运动 |
| 100.367—111.267秒 | 湖湘晚岁 | 768—770年｜湖湘 | 船夫划桨与船体前进，老人翻页 |
| 111.267—120.000秒 | 留在人间 | 770年｜湖南 | 卷轴展开，原创题字逐字出现 |

片名仍为《杜甫：此心在人间》；终章标题改为“留在人间”。章节题是原创，不冒充杜甫诗句。人物新作按自己的生平分章，数量随叙事调整，不能机械套用这12段。
