# 杜甫原生几何场景图层

12幕均为1080×1920原创SVG几何场景，无文字、无地图、无既有图片编辑。人物分青年、中年与暮年，衣冠为简化视觉符号，不宣称历史服饰或具体建筑复原。

每幕文件：本目录 `S01.svg` 和 `S01_full.png` 为完整预览；相邻 `图层/` 提供 `S01_bg`、`S01_mid`、`S01_subject`、`S01_fg` 的独立SVG与PNG。PNG通过Inkscape的分组导出，均为完整1080×1920画布；背景bg完全不透明，其余三层包含真实透明通道，未使用色键抠图。图层次序为bg、mid、subject、fg。

上方文字主区x96～880/y210～700保留浅麻纸或浅苔纸，建议墨绿黑正文。辅助说明x96～880/y1370～1490所在的地面/江水自然延续至1920，不另挖空白横带。每幕辅助区建议文字颜色写在 `场景索引.json` 的 `lower_text_color`，实际运动后仍须检查对比。

纸感属于bg中的低对比固定图案，不是随机动画噪声。S01/S09不含静态雨线，由总渲染器另画动态雨；S09已去掉室内错位的迷你房屋。S07中部留给地图，人物仅在y1280以下作次要行旅示意，不表示家庭人数考据。

从项目根目录重新生成：

```bash
python 工程/build_art.py
python 工程/build_art.py --scenes S02 S09
python 工程/build_art.py --svg-only
```

需要本机Python与Inkscape，不联网，不安装第三方包；脚本使用`__file__`定位项目目录。重跑会覆盖相应同名素材，不改史料数据、音轨或总渲染器。动画、动态排字、音乐卡点、地图与完整成片验收由总工程单独完成。
