# S07 三城叙事关系图说明

本幕使用现代城市约位与经纬网表达秦州→同谷→成都的叙事次序。**没有绘制河流、海岸、山体或行政边界**；本轮没有成功取得真实轮廓数据，因此没有用随机曲线代替地理轮廓。底图的直线只是按真实度数计算的经纬网（片上省略轴刻度文字以减少干扰），生长曲线仅为城市关系。

## 数据取得边界

[Natural Earth河流数据介绍](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-rivers-lake-centerlines/)与[公版许可](https://www.naturalearthdata.com/about/terms-of-use/)均已打开。但实际河流GeoJSON下载没有成功：沙箱内无法连接继承的云代理，外部下载权限调用等待后取消。**没有取得底图文件，因此没有将其绘入本图，也不把已打开介绍页说成已使用数据。** 该过程不影响本图的经纬网计算。

古今地名与759年迁移背景沿用本项目生平核查，本文件只解决现代点位与制图表达。三城之间省略中间行程，不宣称直达；曲线不代表古道、真实路程曲率或精确历史路线。尤其不能沿平滑曲线反推行旅经过的乡镇。

## 制图与集成

- PNG为700×500 RGBA，透明、无实底、无框；仅含低透明度经纬网，**不含路线和城市点**。路线及节点由主渲染器按本幕时间绘制。
- 同一局部等距圆柱近似投影：中央经线105°E、标准纬线32.6°N；经度乘标准纬线余弦，全部数据在同一投影下只用一个像素/米比例。北在上，不把700×500分别横纵拉伸。局部投影有正常的纬向尺度近似，不宣称严格无投影畸变。
- `素材/地图/routes.json`字段为`nodes:[{label,pixel,label_pixel,...}]`和`routes:[{points:[[x,y],...],...}]`；所有像素均相对于700×500图层左上角。路线为端点精确落在这三个显示节点的两段三次Bézier采样。
- 主视频可原尺寸叠加于`(150,754)`；说明文字放在`(185,1240)`附近，检查实际字体宽度，不拉伸图层。数据包含城市名和现代名，当前标签可由主片统一排版。
- 重建：`python 工程/build_map.py`，只需Pillow与Python标准库，无需联网、Basemap、OpenCV或CairoSVG。

建议画面小字：**地点关系示意 · 非历史道路**。说明中的“现代城市约位”含义应同时保留在片后或交付文档。

若需要有真实河流或地形的地图，应在另行成功取得可追溯地理数据后再替换底层。当前交付明确是一张有坐标依据的地理关系示意图，不能称为已完成真实轮廓底图。
